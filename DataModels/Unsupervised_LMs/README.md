# Unsupervised_LMs

Esta carpeta contiene los modelos no supervisados del proyecto.

## Contenido esperado

- Scripts o notebooks de exploracion y modelado.
- Procesos de clustering, segmentacion o deteccion de patrones.
- Resultados de reduccion de dimensionalidad.
- Visualizaciones, metricas y evidencias de analisis.

## Objetivo

Organizar los recursos asociados con tecnicas no supervisadas, utilizadas para descubrir relaciones, grupos o comportamientos sin una variable objetivo etiquetada.
