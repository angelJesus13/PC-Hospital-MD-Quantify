# Unsupervised_LMs

## Descripcion general

La carpeta `Unsupervised_LMs` contiene los modelos no supervisados del proyecto. Esta area esta destinada a tecnicas analiticas orientadas al descubrimiento de patrones, segmentacion de datos y exploracion de estructuras ocultas sin depender de etiquetas previas.

## Objetivo

Su proposito es organizar y documentar los recursos utilizados para identificar comportamientos, similitudes o agrupamientos relevantes dentro de los datos del proyecto.

## Contenido esperado

Aqui pueden almacenarse:

- notebooks o scripts de exploracion y modelado;
- procesos de clustering o segmentacion;
- analisis de reduccion de dimensionalidad;
- visualizaciones de resultados;
- metricas de calidad o separacion de grupos;
- evidencia de hallazgos obtenidos durante el analisis.

## Aplicaciones comunes

Los modelos de esta carpeta pueden utilizarse para:

- deteccion de patrones de comportamiento;
- agrupacion de registros con caracteristicas similares;
- apoyo al analisis exploratorio de datos;
- generacion de insumos para modelos posteriores.

## Buenas practicas

Se recomienda documentar:

- la tecnica utilizada;
- los parametros principales del modelo;
- el criterio de evaluacion empleado;
- las conclusiones obtenidas a partir de los resultados.
