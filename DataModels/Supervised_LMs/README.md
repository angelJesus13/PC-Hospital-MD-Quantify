# Supervised_LMs

## Descripcion general

La carpeta `Supervised_LMs` contiene los modelos supervisados desarrollados para el proyecto. En este espacio se documentan los artefactos asociados con algoritmos entrenados a partir de datos etiquetados, donde existe una variable objetivo definida.

## Objetivo

Su finalidad es concentrar los recursos necesarios para el desarrollo y seguimiento de modelos predictivos o clasificadores, facilitando su consulta, comparacion y mantenimiento.

## Contenido esperado

Esta carpeta puede incluir:

- notebooks o scripts de entrenamiento;
- conjuntos de datos procesados para entrenamiento, validacion y prueba;
- modelos exportados en formatos reutilizables;
- resultados de evaluacion;
- comparativas entre distintos algoritmos o configuraciones.

## Metricas sugeridas

Dependiendo del tipo de problema, se recomienda documentar metricas como:

- `accuracy`
- `precision`
- `recall`
- `F1-score`
- `MAE`
- `RMSE`

## Buenas practicas

Para mejorar la trazabilidad del trabajo, conviene:

- indicar el problema que resuelve cada modelo;
- registrar hiperparametros relevantes;
- asociar resultados con fecha o version del experimento;
- conservar evidencia de pruebas y validaciones.
