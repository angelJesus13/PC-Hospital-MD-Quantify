# Supervised_LMs

Esta carpeta contiene los modelos supervisados del proyecto.

## Contenido esperado

- Scripts o notebooks de entrenamiento.
- Conjuntos de datos procesados para entrenamiento y validacion.
- Modelos exportados o serializados.
- Metricas de desempeno como accuracy, precision, recall, F1-score o MAE/RMSE, segun corresponda.
- Evidencias de pruebas y comparativas entre modelos.

## Objetivo

Centralizar los artefactos relacionados con algoritmos supervisados, donde existe una variable objetivo conocida para entrenamiento y evaluacion.
