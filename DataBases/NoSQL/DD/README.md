# DD

## Descripcion general

La carpeta `DD` (Diccionarios de Datos) almacena la documentacion descriptiva de los documentos y colecciones que componen la base de datos NoSQL del proyecto `PC-Hospital-MD-Quantify`. Su objetivo es proporcionar un glosario claro y formal sobre el significado, tipo y proposito de cada campo almacenado.

## Objetivo

Esta seccion del repositorio sirve como punto de referencia para:

- almacenar las definiciones formales de atributos y objetos anidados;
- conservar descripciones claras sobre la semantica y uso de los datos;
- facilitar la comprension del modelo no relacional por parte del equipo de desarrollo;
- apoyar la estandarizacion de nomenclaturas en los documentos.

## Estructura de carpetas

| Carpeta | Descripcion |
| --- | --- |
| *No aplica* | Los diccionarios se agrupan por modulo o archivo individual dentro de esta carpeta. |

## Contenido esperado

Dentro de esta carpeta pueden incluirse:

- documentos de texto, hojas de calculo (ej. `.csv`) o archivos markdown detallando cada coleccion;
- descripciones de tipos de datos, valores por defecto y campos requeridos;
- notas sobre la logica de desnormalizacion o referencias manuales entre documentos.

## Lineamientos de documentacion

Para mantener esta seccion clara y util, se recomienda:

- actualizar el diccionario inmediatamente despues de cualquier cambio estructural;
- especificar claramente cuando un campo es un objeto anidado o un arreglo, detallando su estructura interna;
- indicar si existen campos obsoletos (deprecated) para guiar futuras limpiezas de datos;
- usar nombres de archivos que coincidan exactamente con las colecciones documentadas.
