# Interfaces Gráficas - WearableApp (Vista de Paciente)

Esta interfaz está diseñada específicamente para ser visualizada desde el dispositivo Wearable y/o la aplicación móvil acompañante del paciente.

## 1. Monitoreo Frecuente (Watchface)
*   **Latidos por Minuto (BPM):** Indicador primario y gigante con el ritmo cardíaco actual.
*   **Saturación de Oxígeno (SpO2):** Indicador secundario en pantalla.
*   **Estado de Transmisión:** Un ícono que certifica que el reloj está enviando los datos exitosamente a la API del hospital en la nube.

## 2. Vista Diaria (Aplicación Móvil del Paciente)
*   **Resumen de Salud:** El paciente puede revisar la estabilidad de sus latidos durante las últimas 24 horas y corroborar que su expediente está actualizado.
*   **Médico Asignado:** Tarjeta informativa que muestra el nombre y especialidad del doctor encargado de vigilar las métricas del paciente.
