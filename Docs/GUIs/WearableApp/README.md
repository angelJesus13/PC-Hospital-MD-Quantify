# WearableApp

En esta carpeta se organiza la documentacion visual de la interfaz grafica de la **WearableApp**. Aqui se pueden incluir capturas, bocetos, prototipos, diagramas de pantallas y evidencias relacionadas con la experiencia de usuario de la aplicacion wearable.

## Estructura de Archivos

```text
PC-Hospital-MD-Quantify
|-- Docs
|   |-- GUIs
|   |   |-- WearableApp
|   |   |   |-- .gitkeep
```

## Contenido Esperado

| Elemento | Descripcion |
| --- | --- |
| Capturas de pantalla | Evidencias visuales de las pantallas principales de la aplicacion. |
| Prototipos | Disenos o maquetas utilizados para planear la interfaz. |
| Diagramas de flujo | Representaciones del recorrido del usuario entre pantallas. |
| Notas de interfaz | Observaciones sobre elementos visuales, navegacion y experiencia de uso. |

## Proposito

Esta carpeta permite concentrar la evidencia grafica de la WearableApp para facilitar su revision, comparacion y mejora durante el desarrollo del proyecto.

## Recomendaciones

- Nombrar las imagenes de forma clara segun la pantalla o funcion que representan.
- Mantener versiones actualizadas de las pantallas principales.
- Documentar cambios importantes en el flujo de navegacion.
- Separar bocetos, capturas finales y evidencias cuando la cantidad de archivos aumente.
