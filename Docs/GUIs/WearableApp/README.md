Este directorio está destinado a almacenar y estructurar los maquetados, flujos y recursos gráficos del diseño de interfaz de la aplicación para **dispositivos corporales (WearableApp)** de **Quantify**.

---

## Definición de Interfaz Wearable

La interfaz para **WearableApp** representa la capa de interacción táctil simplificada y visualización rápida para relojes inteligentes y pulseras de actividad. El diseño está condicionado por pantallas de formato reducido (circulares y cuadradas) y exige una arquitectura de información sumamente eficiente.

En el ecosistema **Quantify**, la WearableApp se enfoca en:
*   Visualización de biometría en tiempo real (ritmo cardíaco, pasos, etc.).
*   Envío y confirmación rápida de logs de disciplina diarios.
*   Notificaciones push micro-gamificadas (alertas rápidas de mantenimiento de racha).
*   Diseño optimizado de alto contraste para visibilidad en exteriores y bajo consumo energético.
