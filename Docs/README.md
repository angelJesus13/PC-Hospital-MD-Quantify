# Documentation

This folder contains all project documentation organized by type.

## Sections

- **[Business Requirements (BRs)](./BRs/)**: High-level business needs and objectives.
- **[Functional Requirements (FRs)](./FRs/)**: Detailed functional specifications.
- **[Non-Functional Requirements (NFRs)](./NFRs/)**: Performance, security, and quality attributes.
- **[User Histories (UHs)](./UHs/)**: User stories and scenarios.
- **[User Requirements (URs)](./URs/)**: End-user needs and expectations.
- **[Graphical User Interfaces (GUIs)](./GUIs/)**: UI/UX designs and wireframes.
