# build

Esta carpeta almacena los artefactos generados durante el proceso de compilacion, empaquetado o preparacion de la API para entrega o despliegue.

## Contenido esperado

- Binarios o paquetes generados.
- Archivos comprimidos para distribucion.
- Resultados del proceso de build listos para ser publicados o desplegados.

## Nota

El contenido de esta carpeta puede cambiar segun la tecnologia utilizada para implementar la API.
