# frontend

En esta carpeta se organiza el frontend de la **WearableApp**. Aqui se deben ubicar los archivos relacionados con la interfaz de usuario, pantallas, componentes visuales, estilos, navegacion e interacciones que permiten al usuario utilizar la aplicacion wearable.

## Estructura de Archivos

```text
WearableApp
|-- source
|   |-- frontend
|   |   |-- .gitkeep
```

## Contenido Esperado

| Elemento | Descripcion |
| --- | --- |
| Pantallas | Vistas principales de la aplicacion wearable. |
| Componentes | Elementos reutilizables de la interfaz, como botones, tarjetas, formularios o indicadores. |
| Estilos | Archivos de apariencia visual, distribucion y diseno responsivo. |
| Navegacion | Configuracion de rutas o flujo entre pantallas. |
| Recursos | Iconos, imagenes, fuentes u otros assets necesarios para la interfaz. |

## Proposito

El frontend permite que el usuario interactue con la WearableApp de forma clara y funcional. Esta capa debe presentar la informacion de manera entendible, facilitar la navegacion y apoyar la consulta o captura de datos relacionados con el monitoreo medico.

## Responsabilidades

- Mostrar informacion relevante del paciente o del dispositivo wearable.
- Permitir la interaccion con funciones principales de la aplicacion.
- Consumir datos proporcionados por el backend o servicios externos.
- Mantener una interfaz clara, ordenada y accesible.
- Preparar componentes reutilizables para facilitar el mantenimiento.

## Recomendaciones

- Mantener los componentes visuales separados de la logica de datos.
- Usar nombres claros para pantallas y componentes.
- Cuidar la legibilidad en pantallas pequenas.
- Documentar flujos principales cuando se agreguen nuevas vistas.
- Verificar que la interfaz sea consistente con el objetivo medico del proyecto.
