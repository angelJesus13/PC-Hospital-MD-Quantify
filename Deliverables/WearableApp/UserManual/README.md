# UserManual

En esta carpeta se organiza el manual de usuario de la **WearableApp**. Su objetivo es explicar de forma clara como utilizar la aplicacion, que funciones ofrece y que pasos debe seguir el usuario final para interactuar correctamente con el sistema.

## Estructura de Archivos

```text
WearableApp
|-- UserManual
|   |-- .gitkeep
```

## Contenido Esperado

| Elemento | Descripcion |
| --- | --- |
| Guia de usuario | Documento principal con instrucciones de uso de la aplicacion. |
| Capturas de pantalla | Imagenes que muestran pantallas, botones y flujos importantes. |
| Descripcion de funciones | Explicacion de las herramientas disponibles dentro de la WearableApp. |
| Solucion de problemas | Recomendaciones para errores o dudas frecuentes del usuario. |

## Proposito

El manual de usuario permite que una persona pueda utilizar la WearableApp sin conocer su implementacion tecnica. Debe explicar los pasos principales de manera sencilla y mostrar el flujo de uso esperado.

## Puntos a Documentar

- Inicio de la aplicacion.
- Permisos necesarios para su funcionamiento.
- Registro o consulta de informacion.
- Visualizacion de datos del wearable.
- Sincronizacion o envio de datos cuando aplique.
- Cierre de sesion o salida segura de la aplicacion.
- Preguntas frecuentes y recomendaciones de uso.

## Publico Objetivo

Este manual esta dirigido a usuarios finales, revisores academicos e integrantes del equipo que necesiten comprender rapidamente el funcionamiento practico de la aplicacion wearable.
