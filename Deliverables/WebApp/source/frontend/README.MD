# 💻 WebApp FrontEnd
La carpeta `Deliverables/WebApp/Source/FrontEnd` contiene el código fuente correspondiente a la interfaz gráfica del sistema web **Quantify**.

Este módulo es responsable de la experiencia visual e interacción del usuario dentro de la plataforma, permitiendo la comunicación con el backend y la visualización dinámica de la información.

# 📖 Descripción General

El frontend representa la capa visual de la aplicación web y permite que los usuarios interactúen con las funcionalidades del sistema mediante componentes gráficos modernos e intuitivos.

Su objetivo principal es ofrecer:

- Interfaces dinámicas y responsivas.
- Navegación eficiente dentro del sistema.
- Comunicación con APIs del backend.
- Experiencia de usuario fluida y organizada.
- Visualización clara de la información.

La estructura del frontend fue diseñada para facilitar el mantenimiento, la escalabilidad y el desarrollo colaborativo.

---

# ⚙️ Funcionalidades Principales

Dentro de este módulo se implementan las siguientes funcionalidades:

- Interfaces gráficas del sistema.
- Navegación entre pantallas y módulos.
- Formularios interactivos.
- Consumo de APIs del backend.
- Gestión de estados y datos.
- Validación visual de información.
- Diseño responsivo para distintos dispositivos.
- Componentes reutilizables.
- Manejo de sesiones y autenticación visual.
- Comunicación en tiempo real.

---

# 🚀 Tecnologías Utilizadas

El frontend fue desarrollado utilizando tecnologías modernas enfocadas en aplicaciones web dinámicas:

| Tecnología | Descripción |
|---|---|
| React | Librería principal para interfaces de usuario |
| JavaScript | Lenguaje de programación principal |
| HTML5 | Estructura de la aplicación |
| CSS3 | Diseño y estilos visuales |
| Axios | Comunicación con APIs |
| React Router | Navegación entre vistas |
| Socket.IO Client | Comunicación en tiempo real |

# 🎯 Objetivo del Frontend

El objetivo principal del frontend es proporcionar una interfaz moderna, intuitiva y eficiente que permita:

- Facilitar la interacción del usuario.
- Mostrar información de manera clara.
- Mejorar la experiencia visual del sistema.
- Optimizar la navegación dentro de la plataforma.

# 📱 Diseño Responsivo

La interfaz fue desarrollada bajo principios de diseño responsivo, permitiendo su correcta visualización en:

- Computadoras.
- Tablets.
- Dispositivos móviles.

Esto mejora la accesibilidad y experiencia de usuario en diferentes resoluciones de pantalla.

El frontend es uno de los componentes principales del sistema **Quantify**, ya que permite la interacción directa entre el usuario y la plataforma.
