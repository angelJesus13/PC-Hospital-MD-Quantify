# 📘 Quantify UserManual

La carpeta `Deliverables/WebApp/UserManual` contiene la documentación orientada al usuario final del sistema **Quantify**.  
Este módulo proporciona guías, instrucciones y procedimientos necesarios para utilizar correctamente la aplicación web.

# 📖 Descripción General

El módulo **UserManual** fue diseñado para facilitar el aprendizaje y uso del sistema mediante documentación clara y organizada.

Dentro de esta carpeta se incluyen:

- Guías de navegación.
- Procedimientos operativos.
- Explicación de funcionalidades.
- Instrucciones de uso del sistema.
- Apoyo para usuarios finales.

La documentación permite mejorar:

- La experiencia del usuario.
- El entendimiento del sistema.
- La facilidad de uso.
- La capacitación de nuevos usuarios.

# 🎯 Objetivo del UserManual

El objetivo principal de este módulo es proporcionar documentación clara y accesible que facilite el uso correcto del sistema **Quantify**.

Gracias a esta documentación, los usuarios pueden comprender rápidamente las funcionalidades de la plataforma y utilizar el sistema de manera eficiente.

---

# 📌 Importancia del Manual de Usuario

El manual de usuario es un recurso fundamental dentro del proyecto, ya que permite:

- Reducir dudas operativas.
- Facilitar la capacitación.
- Mejorar la experiencia de usuario.
- Optimizar el uso de la plataforma.
- Proporcionar apoyo técnico básico.
