# Deliverables

Esta carpeta agrupa los entregables funcionales del proyecto.

## Estructura

- `API/`: entregables relacionados con la interfaz de servicios y backend.
- `WebApp/`: entregables correspondientes a la aplicacion web.
- `WearableApp/`: entregables asociados a la aplicacion wearable.

## Proposito

Mantener organizados los componentes listos para construccion, despliegue, documentacion tecnica y entrega final de cada modulo del sistema.
