# Deliverables

## Descripcion general

La carpeta `Deliverables` agrupa los entregables funcionales del proyecto `PC-Hospital-MD-Quantify`. Aqui se concentran los componentes listos para documentacion, construccion, despliegue y entrega por modulo.

## Objetivo

Esta estructura permite separar de forma ordenada los productos desarrollados dentro del sistema, facilitando su administracion tecnica y academica.

## Estructura principal

| Carpeta | Descripcion |
| --- | --- |
| `API/` | Entregables asociados a la interfaz de servicios y logica backend. |
| `WebApp/` | Recursos correspondientes a la aplicacion web del proyecto. |
| `WearableApp/` | Componentes relacionados con la aplicacion para dispositivos wearables. |

## Contenido esperado

Cada modulo dentro de `Deliverables` puede incluir:

- codigo fuente;
- artefactos de build;
- manuales de despliegue;
- manuales de usuario, cuando aplique;
- archivos necesarios para entrega o demostracion.

## Criterio de organizacion

La finalidad de esta carpeta es que cada componente del sistema cuente con una estructura clara, de modo que cualquier integrante del equipo pueda ubicar rapidamente:

- el codigo base del modulo;
- la documentacion tecnica;
- los archivos listos para ejecucion o distribucion.
