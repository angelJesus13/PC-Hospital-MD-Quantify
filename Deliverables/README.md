# Deliverables

## Descripción general

La carpeta `Deliverables` agrupa los entregables funcionales del proyecto `PC-Hospital-MD-Quantify`. Aquí se concentran los componentes listos para documentación, construcción, despliegue y entrega por módulo.

## Objetivo

Esta estructura permite separar de forma ordenada los productos desarrollados dentro del sistema, facilitando su administración técnica y académica.

## Estructura principal

| Carpeta | Descripción |
| --- | --- |
| `API/` | Entregables asociados a la interfaz de servicios y lógica backend. |
| `WebApp/` | Recursos correspondientes a la aplicación web del proyecto. |
| `WearableApp/` | Componentes relacionados con la aplicación para dispositivos wearables. |

## Contenido esperado

Cada modulo dentro de `Deliverables` puede incluir:

- código fuente;
- artefactos de build;
- manuales de despliegue;
- manuales de usuario, cuando aplique;
- archivos necesarios para entrega o demostracion.

## Criterio de organización

La finalidad de esta carpeta es que cada componente del sistema cuente con una estructura clara, de modo que cualquier integrante del equipo pueda ubicar rápidamente:

- el código base del módulo;
- la documentación técnica;
- los archivos listos para ejecución o distribución.
